# 电商主视觉 Skill v1.3 修改说明

以 01_skills_v1.2 中英文版本为基础；阅读本次指定 00_source_brief 下的 Task.pdf、text.pdf 与 Skill 评价优化课程资料。课程资料用于任务边界、素材保真与测试原则，本次交互修改以使用者明确请求为准；未将课程中的示例参数设为所有任务的通用要求。

## 本次修改

1. 颜色、排版、字体和最终效果的确认不再被理解为永久锁定；使用者可随时修改已选方案。
2. 局部修改默认直接输出该方案的新修订稿和前后对照，不强制重做整套三选一。每次新稿须本人再次确认，继续循环至满意、暂停或取消。
3. “重做当前阶段”“返回上一设计阶段”“恢复上一修订版本”分别处理；不满意时可以明确退回上一步。
4. 带修改条件的确认（如“确认方案2，但标题再大一点”）先执行修改，不能批准尚未展示的新稿。
5. 前序实际修改仅触发受影响后续预览的复查与重新确认；纯导航不清空历史，也不从头重复资料整理。
6. 正式交付后仍支持修订，保留旧交付并另存已验收、已确认的新版本。
7. 更新双语选择规则与输入模板，增加基础版本、修订编号、修改/保留项、回退目标及确认记录。
