- 语言、每种语言张数：
- 比例、像素尺寸、格式：
- 源文件要求与输出位置：

## F. 多方案选择与确认

- 各阶段候选数量（默认 3，至少 2；不改变最终交付数量）：
- 当前阶段与轮次：
- 颜色确认编号、对应预览、用户确认原文：
- 排版确认编号、对应预览、用户确认原文：
- 字体确认编号、对应预览、用户确认原文：
- 最终效果确认编号、对应预览、用户确认原文：
- 确认适用的语言与尺寸：
- 本轮不满意的原因、保留项与重做方向：
- 因上游修改失效的后续确认：

未填写的确认项保持“待确认”，不能自动补成批准。每阶段展示实际多方案后等待本人选择与明确确认；都不满意则返回该阶段的生成步骤重做。详见 [方案选择与回退规则](selection-workflow.md)。


## G. 已选方案修改与回退记录

- 当前操作：修改已选稿 / 重做当前阶段 / 返回上一阶段 / 返回指定阶段 / 恢复旧版本：
- 修改基础编号与已确认版本、对应语言/尺寸：
- 希望修改的颜色 / 排版 / 字体 / 最终效果对象及目标：
- 需要保留的部分：
- 新修订编号、前后对照文件与待确认状态：
- 回退目标阶段或恢复版本（两者分开记录）：
- 受影响的后续预览、复查结果与新的确认原文：
- 满意并确认 / 继续修改 / 暂停 / 取消：

修改要求不等于对未展示新稿的批准。确认后仍可继续修改，正式交付后修订另存；无反馈就等待。详见 [修改与回退规则](selection-workflow.md)。
