# 方案选择、确认后修改与回退规则

## 状态与版本

阶段顺序为颜色 C → 排版 L → 字体 T → 最终效果 F。多方案使用 `C-R01-01` 等编号；R 是候选轮次。选定方案的修订使用 `C-R01-01-V02`，每次调整递增 V，不覆盖旧图或确认记录。复用旧图时明确其版本与上游依据。

记录：当前阶段、操作类型（初次探索/选定方案修改/当前阶段重做/返回前序/恢复旧版本）、基础方案与修订编号、预览及源文件路径、上游版本、改动与保留项、用户反馈和确认原文、语言/尺寸范围、状态（候选/选中待确认/修订待确认/已确认/被拒绝/需复查或重新确认）。保留每次确认的历史；更改不能反向抹去旧版曾被确认的事实，但旧批准不适用于新图。会话恢复时读取这些记录，不把助手摘要当用户批准。

## 选择与确认

1. 初次进入阶段或明确要求重新探索时，默认生成 3 个实质不同的可视方案。用户指定数量时遵从，多方案至少 2 个。
2. 展示编号、实际预览、差异与简短取舍；推荐不是选择。请求使用者选择并明确确认，可同时告知可修改选定稿、重做或返回前序。
3. “确认 L-R01-02”确认唯一对应版本；“喜欢第二个”只表示选中。笼统“可以”仅在上一问唯一指向编号、版本和范围时作为确认。
4. 确认后可按原流程继续，不增加无必要的第二道确认；使用者随时仍可要求修改刚确认或更早确认的方案。确认是当前版本的批准，不是永久锁定，也不表示放弃修改权。

## 在已确认方案上继续修改

收到“选 2 并确认，但标题再大一点”“颜色再浅一点”“这个方案再微调”等请求，先将选定或已确认方案作为修改基础，执行调整，再展示新版本；不能把带有修改条件的确认当作对尚未生成结果的批准或直接进入下一阶段。

| 维度 | 可调整的对象 | 保留的基础 |
| --- | --- | --- |
| 颜色 | 背景、主辅色、强调色、面积、明暗及对比 | 商品原色、Logo 原素材、准确母本与未被要求调整的结构 |
| 排版 | 主体/标题位置与尺度、阅读层级、留白、对齐、信息密度 | 已确认配色与未涉及的字体规则，商品保持等比缩放 |
| 字体 | 字体搭配、字重、字号、行距、字距、各语言断行 | 已确认颜色及结构，调整字形引发的换行或布局影响须展示 |
| 最终效果 | 背景质感、光效、装饰、阴影、边缘及细节 | 已确认颜色、布局、字体和原商品/Logo，影响前序项时回到相应阶段 |

默认只提供该方案的一张真实修订稿及旧版/新版对照，明确修改内容和未变部分，不强制把每次微调重新变成三选一。反馈存在多个合理方向或用户要求备选时，再提供多种修订分支。明确可执行的修改直接做；只对影响范围或方案指向的必要歧义澄清。

新修订标“待确认”，检查受影响的事实、保真、可读性及规格后展示。请求用户确认新版本、继续修改、恢复旧版或回退。每次反馈执行一轮，等待下一次反馈；用户继续修改就继续此循环，直到本人明确满意并确认、暂停或取消。旧版确认不得自动传给修订稿；未获确认不推进依赖步骤或作为正式成品。

## 重做、退回上一阶段与恢复

| 用户意图或反馈 | 执行动作 |
| --- | --- |
| “重做”“都不喜欢”，未指定返回阶段 | 在当前阶段重新生成多方案；保留已确认前序项，不擅自回到任务起点。 |
| “退回上一步”“返回上一阶段” | 按 C → L → T → F 退回一个设计阶段：F→T、T→L、L→C。颜色已是第一阶段时回到配色生成，不要求重新提供全部资料。展示目标阶段的最近版本，可继续修改或重新探索。 |
| “退回颜色/排版/字体阶段” | 直接定位指定阶段及其已选基础，不逐级反复追问。 |
| 对当前修订不满意 | 继续修改同一基础，或按用户要求恢复旧版、重做/回退；不把不满意强行解读为放弃整套方案。 |
| “恢复上一个版本” | 回到当前方案的上一个修订版本，不等同于返回上一设计阶段。显示恢复的版本和适用范围；上游版本已改变时先复查再确认。 |
| “选择 A 的颜色加 B 的排版” | 生成新组合编号的真实预览再确认，不把组合要求当批准未展示的结果。 |
| 已正式交付后继续修改 | 基于指定正式版本开启修订分支，保留旧交付；修订通过验收并确认后另存新交付，不覆盖旧包。 |

单纯导航回到前序阶段不改变已确认画面，也不立即废除全部后续确认。实际修改前序项时，将该阶段新版本置为待确认，并列出后续受影响项；若尚不确定，标“需复查”。变更颜色可能影响文字对比与最终光效，变更布局可能影响字体断行及效果，变更字体可能影响布局，变更效果通常只影响效果阶段。把有影响的后续预览重新渲染、检查并确认；未受影响的选择保留，可复用结构、字体和装饰，不强制生成新的整套多方案。不沿用基于旧上游的成品批准。确认记录始终绑定实际版本和适用语言/尺寸。

用户可限定只改中文、英文或某个尺寸；只修改授权范围，展示所改版本及必要的跨版本一致性检查。母本文字、商品外形/颜色和 Logo 保护规则仍有效，审美修改不授权改写事实或重绘受保护素材。

每轮结束等待反馈，沉默、超时或预选不是同意；“停止”“中止”“取消”立即结束生成并保存进度。“直到满意”不是无人反馈时无限循环，也不自动授权超出当前工具、预算或时限的执行。若实际限制阻止继续，说明限制和已完成内容，等待调整范围。

## 行为验证情境（待实际执行）

- 已确认颜色后要求“背景再浅一点”：在选定颜色基础上制作 V02，保留商品原色，等待新确认。
- “确认方案 2，但标题再大一点”：先生成改大标题的修订，不把原话当成新稿已批准。
- 字体阶段说“退回上一步”：返回排版阶段，展示已选布局，允许修改；尚未修改时不清空历史确认。
- 最终效果阶段说“回到颜色”：直接返回颜色，修改后复查并重新确认受影响后续预览。
- V03 不喜欢并要求“恢复上一版”：展示 V02；若上游未变且该版仍有效，可恢复原确认，否则重新确认。
- 只改英文行距：不擅自改变中文，检查英文布局影响并展示确认。
- 最终稿已交付后要求柔化阴影：保留旧包，制作新效果修订并确认后另存。
- 用户沉默或中止：不自动批准、不继续生成。

这些情境是测试输入与预期行为，不是已完成运行的证据。真实海报复测、Token/时间比较与同学互测另行执行并记录。
